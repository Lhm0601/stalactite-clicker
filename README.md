# 石钟乳工坊 · Stalactite Clicker

一个以石钟乳/石笋生长为主题的增量（Idle/Clicker）小游戏，单文件、零依赖，浏览器直接打开即玩。

## 玩法

- 点击洞穴任意处收集方解石（CaCO₃）
- 用方解石购买升级：更湿的雨季 / 裂隙拓宽 / 酸性土壤 / 地下暗河 / 时间加速器
- 石钟乳与石笋随累计产量真实生长，最终相连成石柱
- 里程碑：鹅管 → 幼年石钟乳 → 成熟石钟乳 → 石柱（附真实地质时间科普）
- 自动存档（localStorage，每 10 秒 + 关页时），支持离线收益结算

## 运行

直接用浏览器打开 `index.html` 即可，无需构建、无需服务器。

## 数值模型

- 1 方解石 = 0.01 mm 沉积
- 升级价格按 ×1.15 ~ ×1.25 指数增长
- 时间加速器：全局产量 ×3，限购 5 次

## 技术

- 单 HTML 文件，Canvas 2D 渲染洞穴，DOM 渲染升级面板
- 无外部依赖，无 CDN
- 存档：`localStorage` key `stalClicker`
